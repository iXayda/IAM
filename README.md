# IAM

简体中文 | [English](README.en.md)

IAM 是面向单个组织、多个自有应用的身份与访问管理项目，让各应用共用账号和登录体系，集中管理用户、应用角色、会话和安全审计。

## 适用场景

- 多个自有应用需要统一账号和单点登录。
- 需要集中管理用户开通、停用、密码恢复及应用访问权限。
- 需要统一查询和撤销会话，并追踪关键安全操作。

IAM 负责账号、身份认证和应用级授权；业务对象及具体业务操作的权限由接入应用执行。
